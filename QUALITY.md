# LITF Games & Experiences — Quality Rankings

_Updated by hourly cron cycles. Honest assessments, not self-congratulation._

## Quality Tiers (Scored /100)

- **S-tier (90-100)**: Would genuinely recommend to a stranger. Unique, polished, glasses-native.
- **A-tier (76-88)**: Ship proudly. Strong on most dimensions.
- **B-tier (60-74)**: Solid but has weaknesses. Improve or accept the gap.
- **C-tier (40-58)**: Cut candidate. If it can't be improved to B in 2 cycles, remove it.
- **F-tier (<40)**: Doesn't belong. Phone does it better, no real trigger, or broken.

## Minimum Standards
- New games/experiences must score 60/100 or higher to ship
- Score honestly. If a game truly deserves 90+, give it 90+. But be rigorous — a 90 should feel meaningfully better than an 88.
- Anything below B-tier gets 2 improvement cycles, then gets cut
- Indexes ordered by score (highest first)

### What changed
Under the old 6-dimension/30-point rubric, 9 of 16 games scored 30/30 (S-tier) because adding rank progression was a universal cheat code. The 4 new dimensions (Session Variance, Strategic Depth, Surprise/Discovery, Craft) expose the difference between genuinely replayable games (Dungeon Crawl: procedural rooms, fight/flee decisions, emergent encounters) and good-but-repetitive games (Beacon: same beam-sweep loop every time).

## Evaluation Criteria (for honest re-assessment)

When re-evaluating, actually READ the HTML source. Check:
1. **Does it actually work?** Load it mentally — are there JS errors, broken logic, impossible states?
2. **Is the code quality good?** Or is it 3000 lines of spaghetti with duplicate event listeners?
3. **Would a REAL person use this?** Not "could someone theoretically..." but "would my friend actually open this?"
4. **Does it feel good in 5 seconds?** First impression matters more than feature count.
5. **Is the audio annoying or delightful?** Through bone conduction, not laptop speakers.
6. **D-pad navigation — smooth or awkward?** Try every button mentally.
