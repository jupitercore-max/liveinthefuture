🎯 Surprising Findings

1.Opus loses to Sonnet. Claude Opus 4.6, the most expensive model tested ($0.76 for 25 prompts), scored 7.5/10 — lower than its own mid-tier sibling Sonnet 4 at 8.1/10. Opus was wordy (5.6 conciseness) and ironically worse at following instructions (7.1 vs 9.0). The "smarter" model overthinks and overproduces. You're paying 6x more for worse results.
2.Haiku is 96% cheaper and 1% worse. Claude Haiku 4.5 scored 8.0/10 for $0.031 total. That's $0.004 per quality point vs Opus at $0.102 per quality point — a 25x cost efficiency advantage. For group chat and creative writing, Haiku was statistically indistinguishable from Sonnet.
3.GPT-5 is broken. The newest OpenAI model returned completely empty responses on all 5 research analysis prompts. Its creative writing scored 3.6/10. At $0.915 total cost, it was the most expensive AND worst performer. This may be an API routing issue via the APE proxy, but the failure mode itself is concerning.
4.Free beats expensive. Llama 4 Maverick scored 7.7/10 for $0.00. That's higher than Claude Opus ($0.76) and GPT-5 ($0.92). The open-source model outperformed both premium offerings. The gap between free and paid has compressed to 5% quality for 100% cost savings.
5.Gemini doesn't know how to just respond. When asked to respond to a group chat message about a puppy, Gemini 2.5 Pro generated "Here are a few natural ways to respond" with 4 options. It treated a social interaction as a multiple-choice exam. Despite scoring 8.0 overall (the numbers are good), it has a persistent "AI assistant" personality leak.
6.Opus is the only model that got 10/10 on anything. Despite its overall lower ranking, Opus scored perfect 10.0 on reasoning accuracy. When the problem actually requires deep thinking (bat-and-ball, birthday paradox), Opus is still the best brain in the room. The issue is that most tasks don't need that brain.

Classic cognitive bias test. Correct answer: $0.05. Most humans say $0.10.

Claude Opus 4.6 — 10.0 ✓
Ball costs $0.05. If ball = x, then bat = x + 1.00. Together: x + (x + 1.00) = 1.10, so 2x = 0.10, x = 0.05. The intuitive wrong answer is $0.10.
Claude Sonnet 4 — 9.8 ✓
Ball costs $0.05. Set up: ball = x, bat = x + 1.00. Solve: 2x + 1.00 = 1.10, x = 0.05. Verify: 0.05 + 1.05 = 1.10 ✓
Claude Haiku 4.5 — 10.0 ✓
$0.05. Let ball = x. Bat = x + $1.00. Total: x + (x + $1.00) = $1.10. 2x = $0.10. x = $0.05.
GPT-4o — 10.0 ✓
The ball costs $0.05. Common mistake: people say $0.10 because they subtract. But if ball = $0.10, bat = $1.10, total = $1.20 ≠ $1.10.

🎬 Verdict: What Should You Actually Use?

For an always-on agent (like OpenClaw): Claude Sonnet 4. Best instruction-following (9.0), strong across all categories, reasonable cost. The "boring correct" choice.

For group chat / casual interaction: Claude Haiku 4.5. Scored 8.0 on group chat — same as models 4-25x more expensive. Fastest responses. Cheapest by far.

For hard reasoning problems: Claude Opus 4.6. Still the accuracy king (8.7, with 10.0 on reasoning). Use it as a specialist, not a generalist. Route complex math and logic to Opus, everything else to Sonnet.

For cost-zero deployments: Llama 4 Maverick. 7.7/10 for free. Self-hostable. The fact that it outperformed both premium models in this eval should make every CFO reconsider their API budget.

For maximum conciseness: Claude Haiku 4.5 (7.8 conciseness). It says what needs saying and stops. GPT-4o (7.1) is second. Opus physically cannot be brief (5.6).

Avoid for now: GPT-5 via this API. Empty responses on research, low creative scores. May improve; this is one test via one proxy.

⚖️ Honest Limitations

Judge bias: Claude Sonnet 4 judged all responses. It may systematically favor Claude-style outputs. A proper eval would use multiple judge models.

Small sample: 25 prompts per model across 5 categories. Statistical significance is limited. One bad prompt can swing a category by 2 points.

API proxy: All models were accessed via the Wearables APE API, not directly. GPT-5's failures may be routing/proxy issues, not model issues.

No images: All prompts were text-only. Scene analysis used text descriptions, not actual images. Multimodal performance was not tested.

Temperature 0.7: All models used the same temperature. Some models may perform differently at different temperatures.

No system prompts: Raw user prompts only. Agent performance with SOUL.md, memory files, and tool definitions would differ significantly.

Single run: No repeated runs to measure variance. Some models may have higher output variance than others.

🔬 Methodology

  1. 25 prompts designed across 5 categories (5 per category): scene analysis, group chat, research analysis, reasoning/logic, creative writing
  2. Each prompt sent to all 7 models via Wearables APE API (OpenAI-compatible endpoint) with temperature=0.7, max_tokens=800
  3. Responses collected in parallel (6 concurrent threads) — wall clock ~8 minutes for 175 responses
  4. All 175 responses blind-judged by Claude Sonnet 4 on 5 dimensions (accuracy, naturalness, depth, instruction_following, conciseness) scored 0-10
  5. Initial judging pass had JSON extraction failures for 104/175 responses (mostly non-Anthropic models). All re-judged with improved prompt and retry logic — 104/104 fixed.
  6. Aggregates computed per model, per category, and overall. Cost calculated from published API pricing per million tokens.
  7. Total API spend for the entire evaluation: approximately $2.09 (dominated by Opus and GPT-5 output tokens)
