# new.rayhe.net

Personal website and tool collection at [rayhe.net](https://rayhe.net).

## Tools

- **World Timer** — analog clock with 24-hour ring, city labels, polar Earth view, and day/night shading
- **Chronograph** — precision stopwatch with tachymeter and pulsometer scales
- **FOV Calculator** — field of view and pixels-per-degree metrics for displays and headsets
- **Dylos PM2.5** — convert Dylos air quality particle counts to PM2.5 and AQI
- **Voice Trivia** — speech-recognition trivia game
- **Voice Math** — mental math flashcards for kids with voice input

## Quick Utilities (on homepage)

JSON formatter, Unix timestamp converter, UUID generator, SHA hash generator, URL encode/decode, Base64 encode/decode, text transform with character/word/line counts.

## Stack

Plain HTML, CSS, and JavaScript. No build tools or frameworks.
