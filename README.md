# Live in the Future

Data-driven dispatches from tomorrow. A publication at [liveinthefuture.org](https://liveinthefuture.org).

One human + AI systems producing investigative journalism across technology, science, and policy. Every article is AI-generated, AI-critiqued through a multi-agent quality eval loop, and human-directed. Under current U.S. copyright law, the AI-written text isn't copyrightable. [We wrote about that.](https://liveinthefuture.org/stories/ai-copyright-our-own-reckoning.html)

## Quality Process

Articles go through a multi-agent eval loop:
1. Research draft with sourced citations
2. Critique by 3-5 separate AI agents (factual accuracy, argument strength, readability)
3. Multiple revision cycles
4. Human editorial direction at every stage

Games are scored on 10 dimensions (Trigger / Hook / Glasses / Return / D-Pad / Audio / Session Variance / Strategic Depth / Surprise / Craft) and ranked in `QUALITY.md`.

## Stack

Static HTML/CSS/JS. No build tools, no frameworks, no CMS. Articles are hand-authored HTML files.
