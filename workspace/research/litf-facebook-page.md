## Setup Steps

1. **Create the Page:**
   - Go to facebook.com/pages/create
   - Enter "Live in the Future" as page name
   - Select "Science & Technology Website" as category
   - Add the short description

2. **Set Username:**
   - Page Settings → General → Username
   - Try @liveinthefuture

3. **Upload Images:**
   - Upload chosen PFP variant as profile picture
   - Upload chosen cover variant as cover photo

4. **Fill in Details:**
   - About → Edit Page Info
   - Paste long description, mission, website, contact email
   - Add secondary category: News & Media Website

5. **Connect Instagram (if applicable):**
   - Page Settings → Linked Accounts → Instagram
   - Connect the LITF Instagram account (once created)

6. **Content Strategy:**
   - Each published LITF article gets a link post with:
     - Hero image
     - Article headline
     - 2-3 sentence hook (not the subtitle — a custom teaser)
     - Link to liveinthefuture.org/stories/...
   - Post frequency: 3-5x per week (matches article cadence)
   - Can be automated via Kit's article cron pipeline
