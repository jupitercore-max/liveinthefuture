## Tableau Extraction Protocol SOLVED (afternoon 3/30)
- Full protocol documented at ~/workspace/research/education/ucop-tableau-protocol.md
- **Three-step process:**
  1. Navigate to embed URL, get session ID from performance.getEntriesByType('resource')
  2. POST to `commands/tabsrv/export-crosstab-to-csvserver` with `sheetdisplayname=FR+ENR` → returns `resultKey`
  3. GET `tempfile/sessions/{sessionId}/{resultKey}.csv` → downloads CSV
- **Blocking issue:** tempfile URL sends Content-Disposition:attachment, Chrome treats as navigation, kills page context
