## Thesis
The spider silk industry has a billion-dollar graveyard of startups that tried to produce the material via fermentation (yeast, bacteria). All pivoted or collapsed. Kraig Biocraft Laboratories, a $107M penny stock, took a different route: put spider silk genes into silkworms using recombinant DNA, then farm them the way humans have farmed silk for 5,000 years. In May–June 2026 they produced 2.5 metric tons of recombinant spider silk cocoons in a single cycle — a world record. They're targeting 10 MT/month by end of 2026.

## Original Contribution
**Cost-per-toughness analysis:** Nobody has publicly run the numbers comparing spider silk's cost economics on a toughness-adjusted basis against Kevlar, carbon fiber, and conventional silk. This is the correct metric for energy-absorbing applications (body armor, crash structures, surgical sutures) but every published comparison uses raw tensile strength, where Kevlar wins easily. On toughness — the energy absorbed before failure — spider silk is 3–6× superior. The question is whether Kraig can produce it cheaply enough to be competitive on $/MJ·m⁻³.

**R&D-per-kg-of-output comparison:** Cross-referencing total capital raised by each competitor against actual commercial fiber output. Bolt Threads: ~$350M raised, 0 kg fiber. Spiber: $640M+, pivoted away from spider silk. Kraig: ~$60–80M cumulative burn (est.), 2.5 MT cocoons in a single cycle.

## The Calculation

### Cost-per-toughness analysis

**Conventional pricing:**
- Kevlar: ~$25–40/kg
- Carbon fiber: ~$15–30/kg
- Conventional silk: ~$25–60/kg
- Steel wire: ~$1–2/kg

**Cost per unit toughness ($/MJ·m⁻³):**
- Kevlar: $30/kg ÷ 50 MJ/m³ per unit mass × density = need to normalize
  - Better: $/kg ÷ specific toughness (MJ·m⁻³ ÷ density g/cm³ → MJ·m/kg)
  - Kevlar specific toughness: 50/1.44 = 34.7 MJ·m/kg → $30/34.7 = $0.86 per MJ·m/kg
  - Carbon fiber: 25/1.8 = 13.9 MJ·m/kg → $20/13.9 = $1.44 per MJ·m/kg
  - Steel: 6/7.8 = 0.77 MJ·m/kg → $1.50/0.77 = $1.95 per MJ·m/kg
  - Spider silk: 200/1.3 = 153.8 MJ·m/kg → $X/153.8 per MJ·m/kg
  
**Break-even:** For spider silk to match Kevlar on cost-per-specific-toughness:
$X/153.8 = $0.86 → X = $132/kg

For spider silk to BEAT Kevlar by 2×:
$X/153.8 = $0.43 → X = $66/kg

**Key insight:** If spider silk can be produced at conventional silk prices ($25–60/kg), it already beats Kevlar on cost-per-toughness by 2–5×. This is the number nobody has run.

### R&D efficiency comparison
- Bolt Threads: ~$350M / 0 kg commercial spider silk fiber = ∞ $/kg
- Spiber: ~$640M / ~500,000 kg claimed capacity (generous) = $1,280/kg R&D cost
- Kraig: ~$60–80M cumulative / 2,500 kg in one cycle (annualized ~30,000 kg at current rate, 120,000 kg at target rate) = $500–2,700/kg R&D cost, dropping fast
