# Research: UK Hybrid Navy — £5B Drone Pivot, Type 83 Cancelled

## Topic
UK cancels Type 83 destroyer replacement, pivoting to autonomous uncrewed vessels (Types 91-94) plus £5B ($6.6B) drone investment across all services. Announced June 30, 2026 by PM Starmer as part of £298B defence investment plan.

### 2. The War Zone — UK Hybrid Navy Details (June 30, 2026)
- Type 83 destroyer programme cancelled
- Four new uncrewed vessel types announced:
  - Type 91: uncrewed missile platform ("floating magazine"), ~70m, ~800 tonnes
  - Type 92: uncrewed ASW "sense platform", ~90m, ~1,500 tonnes
  - Type 93: extra-large uncrewed underwater vessel (XLUUV), sensors + weapons
  - Type 94: uncrewed air defense sense platform, ~100m, ~3,500 tonnes
- At least 6 Common Combat Vessels (crewed control hubs) replacing Type 83, arriving 2030s
- Concept: "hybrid fleet" mixing crewed motherships with uncrewed consorts

## Original Calculation: Magazine Depth Economics

**Core question:** How many Type 91 "floating magazines" could the Royal Navy field for the cost of the cancelled Type 83 destroyer, and what's the aggregate firepower comparison?

### Type 83 baseline:
- Expected cost: £2-3B per ship (based on Type 45 cost escalation trajectory + Type 26 at £1.4B)
- Crew: estimated 200-250 (similar to Type 45's 191 but larger hull)
- Missile cells: likely 96-128 (based on comparable Arleigh Burke Flight III at 96 VLS cells)
- Annual operating cost: ~£40-50M/ship (crew + maintenance + fuel)

### Type 91 uncrewed missile platform estimate:
- At ~800 tonnes displacement, roughly 1/10th a Type 83
- No crew quarters, galley, damage control systems, life support = massive weight/cost savings
- Estimated build cost: £80-150M per hull (based on USV cost comparisons: DARPA Sea Hunter was $20M at 145 tonnes; scale factor for 800 tonnes with missile systems)
- Operating cost: ~£3-5M/year (no crew, reduced maintenance, simpler systems)
- Missile cells: estimated 16-32 per hull (limited by displacement)

### The math:
- Cost of one Type 83: ~£2.5B (midpoint estimate)
- Type 91s purchasable for same cost: 17-31 hulls (at £80-150M each)
- Aggregate VLS cells: 272-992 cells vs ~112 on one Type 83
- Annual operating savings: £40-50M (one Type 83) vs £51-155M (17-31 Type 91s)
  - Note: at the low end (17 hulls × £3M), cost is comparable; at high end, dispersed fleet costs more to operate

### Better calculation angle — cost per sensor-hour at sea:
- Type 45 patrol day cost: ~£31.3M/yr support ÷ ~200 sea days = ~£157K/day
- Add crew cost: £8.6M/yr ÷ 200 days = £43K/day  
- Total Type 45 cost per day at sea: ~£200K/day
- Type 92/94 uncrewed sensor platform cost per day: estimated £15-30K/day (no crew, simpler hull, less fuel for smaller vessel)
- Cost reduction factor: 7-13x cheaper per sensor-day at sea
- For the same annual budget as ONE Type 45, you could sustain 7-13 uncrewed sensor platforms

## Strongest Counterargument
Uncrewed vessels have never operated in contested waters. The Houthis sank or damaged 80+ commercial ships in the Red Sea using cheap anti-ship missiles — crewed warships survived because human damage control teams fought fires, plugged holes, and kept systems running. A Type 91 floating magazine taking a hit has no one to save it. The Royal Navy is betting that expendability + numbers beats survivability + crew — a theory proven in Ukraine's drone war on land but completely untested at sea.

## Limitations
- Type 91-94 costs are estimates; no contracts awarded yet
- Type 83 never reached design phase, so its cost is extrapolated from trends
- UK MOD has a poor track record on cost estimates (Type 45 was 70% over budget)
- Operating cost comparisons assume mature uncrewed systems; early units will cost far more
- No data on uncrewed vessel sea-state endurance vs crewed warships
