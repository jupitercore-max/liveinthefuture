# Research: Samsung's AI Memory Tax — $89.4T Won in Chip Profit, First-Ever Mobile Loss

## Topic
Samsung's Q2 2026 earnings reveal the most dramatic corporate self-cannibalization in tech history: its chip division posted a 19-fold profit jump ($58.44B operating profit) while its mobile division is expected to post its first-ever quarterly loss — because the AI-driven memory prices that make Samsung's chip division enormously profitable are the same prices that make Samsung's own phones unprofitable.

### Internal Transfer Pricing (KEY ORIGINAL ANGLE)

- Samsung CANNOT discount for its own phone division without shareholder/governance issues
- Memory supply contracts capture all upside volatility via quarterly renegotiation
- SOURCE: Mohammed Brückner/Medium (Jan 2026), WCCFTech, Money Today

### BOM Cost Structure Shift

- Combined memory: ~38% of phone BOM (was <20%)

- Budget phone (<$200): RAM expected >33% of manufacturing cost by mid-2026
- LPDDR4 spot: +38% QoQ

- Samsung phasing out LPDDR4 to allocate capacity to AI customers
- SOURCE: Counterpoint Research, TechInsights, FNNews, Archyde

## Original Calculations (REQUIRED FOR LITF)

### Calculation 1: Samsung's Internal Memory Tax Per Phone
- Internal LPDDR5X price: $33 → $70 per 12GB (increase: $37)
- NAND ASP increase: ~53% QoQ. If base NAND cost was ~$25, increase = ~$13
- Total memory cost increase per flagship: ~$50
- Samsung shipped 62.8M phones in Q1 2026 at ~12GB average
- Additional memory cost burden: 62.8M × $50 = ~$3.14B per quarter
- Samsung MX's operating profit in a good year: ~$8-11B annually (~$2-2.75B/quarter)
- The memory cost increase ALONE exceeds the mobile division's entire profit margin

### Calculation 2: How Many Phones One AI Rack Displaces
- One Vera CPU: 1.5TB = 1,500GB LPDDR5X
- Galaxy S26 Ultra: 12GB LPDDR5X
- 1,500 / 12 = 125 phones per CPU
- NVL144 rack: 36 CPUs → 36 × 125 = 4,500 phones (sources say ~4,600 with overhead)
- Nvidia shipped ~1.5M datacenter GPUs in 2025
- At 72 GPUs per rack: ~20,833 racks
- 20,833 × 4,500 = ~93.75M phones' worth of memory
- Samsung's quarterly phone output: 62.8M units × 12GB = 753.6TB
- Nvidia rack output: 20,833 × (36 × 1.5TB) = 1,125TB per wave
- AI servers are consuming 1.5× Samsung's entire quarterly mobile memory allocation

### Calculation 3: Samsung DS Profits FROM Samsung MX
- Samsung MX ships ~62.8M phones/quarter × 12GB LPDDR5X = 753.6TB
- At $70 per 12GB module: 62.8M × $70 = $4.396B in memory purchases
- Samsung DS memory margin: estimated ~45-50% on LPDDR5X
- Samsung DS profit from MX purchases: ~$2.0-2.2B per quarter
- Samsung MX expected loss: $364-729M
- Samsung DS earns MORE from selling memory TO Samsung MX than Samsung MX earns from selling phones TO consumers
- Samsung the chipmaker makes ~3-6× more money FROM Samsung the phonemaker than Samsung the phonemaker makes total
